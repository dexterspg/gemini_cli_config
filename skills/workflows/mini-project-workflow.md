# Mini Project Workflow


## Steps
product-strategist (Mini sizing) → ui-design (if UI) → system-architect --lite → implementation-engineer → qa-engineer

## Rules
- Strategist MUST use Mini project sizing (3-5 stories, 8-12 FRs, minimal NFRs)
- Architect uses --lite mode (implementation brief, not full architecture doc)
- Quality guardian review is optional — user decides at the end
- If the project follows an existing pattern, pass the sister project path to the architect
