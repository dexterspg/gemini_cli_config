# Documentation Generation Workflow


## Steps
archaeologist (README, INTEGRATION, API-REFERENCE, FRONTEND, DEPLOYMENT Security → Auth Request Flow) → tech-detective (TECH-STACK) → system-architect --infra (DEPLOYMENT infra sections, ARCHITECTURE) → concept-tutor (BUSINESS-CASE) → quality-guardian reviews all files

## Routing
APPROVED → done; DOCUMENTATION_ISSUE → route to original writing agent based on which file failed (max 2); CONTENT_ISSUE → concept-tutor (max 1)

## Note
Without "with review" / "and review", use the linear `docs-to-notebook-workflow` instead (no orchestrator needed).
