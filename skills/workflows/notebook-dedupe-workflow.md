# Notebook Dedupe Workflow

**Triggers:** "check for duplicates", "dedupe my notes", "clean up notebook"

## Flow

1. note-taker scans for duplicates
2. Presents ENRICH / RELATE / SEPARATE matrix to user
3. User decides action for each duplicate set
4. Execute user's decisions
5. DONE
