# Documentation: Audience & Voice

Match the writing style to the primary reader of each document.

| Document | Primary Audience | Writing Voice |
|----------|-----------------|---------------|
| README.md | New Developers | Technical but approachable. |
| INTEGRATION.md | Service Owners | Precise. Contracts that can break. |
| DEPLOYMENT.md | DevOps / Local Dev | Dense, copy-paste ready. |
| API-REFERENCE.md | Consumers | Cop-paste ready, zero ambiguity. |
| FRONTEND.md | UI Developers | Component-oriented. |
| TECH-STACK.md | Developers / DevOps | Dense, version-exact. No fluff. |
| BUSINESS-CASE.md | Stakeholders | Zero jargon, value-focused. |
| DATABASE.md | Data Consumers | Relationships first. |
| DOMAIN.md | Logic Developers | Mental model first. |
| domain/*.md | Area Specialists | Logic + Troubleshooting + Future Proofing. |
