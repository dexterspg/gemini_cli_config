# Prompt Builder Skill

Decision framework and templates for building copy-paste ready AI prompts.

## Templates

| Type | Description | File |
|------|-------------|------|
| **Rule-capture** | Extract business logic, rules, and decisions. | `rule-capture.md` |
| **Artifact-generation** | Prompts that generate visualizations, HTML, or SVG. | `artifact-generation.md` |
| **ASCII Animated Diagram** | Specialized prompts for HTML-based sequence animations. | `ascii-animated-diagram.md` |
| **Automation-trigger** | Prompts for recurring multi-agent pipelines (/loop, cron). | `automation-trigger.md` |

## Usage

1. **Classify** the request into one of the types above.
2. **Read** the corresponding template file.
3. **Extract** the core logic or technical specs from the source material.
4. **Structure** the final prompt using the template's format.
5. **Finalize** for portability across AI platforms.
